# Triage labels

Engineering skills use these canonical roles in this repository's GitHub issue tracker.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Waiting on the reporter for more information. |
| `ready-for-agent` | `ready-for-agent` | Fully specified work ready for an autonomous agent. |
| `ready-for-human` | `ready-for-human` | Work requiring human implementation or judgment. |
| `wontfix` | `wontfix` | Work that will not be actioned. |

When a skill names a triage role, use the corresponding label above. Other labels, such as `bug`, `enhancement`, and `documentation`, describe the issue separately from its triage role.

Edit this mapping if the project's vocabulary changes. Check that a configured label exists before applying it.
