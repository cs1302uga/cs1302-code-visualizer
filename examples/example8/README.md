# Example 8: Multi-Dimensional Arrays

This example demonstrates 2D arrays in Java (arrays of arrays) on the heap.

## Concepts Illustrated

- **Array of Arrays**: `int[][] matrix` represented as a root array containing references to row array objects.
- **Element Assignment**: Assigning primitive values into matrix indices.

## Files

- `Driver.java`: Allocates a `2x3` integer matrix and initializes its entries.
