# Example 6: Java Collections & Maps

This example demonstrates how Java standard library collections (`ArrayList`) and maps (`HashMap`) are represented on the heap.

## Concepts Illustrated

- **Reified Collections**: Recovers generic types (`java.util.ArrayList<java.lang.String>` and `java.util.HashMap<java.lang.String, java.lang.Integer>`).
- **Dynamic Sampling**: Inspecting collection elements and key-value entries.

## Files

- `Driver.java`: Populates an `ArrayList` and `HashMap`.
