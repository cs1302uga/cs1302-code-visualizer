# Example 10: Multi-File Packages

This example demonstrates compiling and tracing multi-file packaged classes under a package namespace (`cs1302.example`).

## Concepts Illustrated

- **Java Packages**: `package cs1302.example;`
- **Multi-File Sources**: Separately defined `Person.java` and `Driver.java` compiled into the same source tree.

## Files

- `cs1302/example/Person.java`: Record definition.
- `cs1302/example/Driver.java`: Driver class using `Person`.
