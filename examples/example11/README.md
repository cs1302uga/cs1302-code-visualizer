# Example 11: Primitive Loop Summation & Formatted Output

This example demonstrates iterative loop execution (`trace -a`) with primitive local variables and `System.out.printf` console output capture.

## Concepts Illustrated

- **Primitive Variables**: Loop counter `i` and accumulator `sum`.
- **Chronological Execution**: Line-by-line step tracing across each loop iteration.
- **Stdout Capture**: Recording output emitted to standard output.

## Files

- `Driver.java`: Iteratively computes a sum and prints formatted output.
