# Example 5: Recursion & Call Stack Frames

This example demonstrates recursive function execution and call stack frame growth and unwinding.

## Concepts Illustrated

- **Call Stack Frames**: Successive invocation of `factorial(n)` creating new stack frames with independent `n` parameters.
- **Base Case & Return Unwinding**: Returning base values back up the call chain.

## Files

- `Driver.java`: Implements and traces recursive `factorial(4)`.
