# Example 14: Multi-File Packaged Execution & Stdin Streaming

This example demonstrates how multi-file Java packages can be streamed directly into Tracer and executed step-by-step.

## Concepts Illustrated

- **Multi-File Packages**: `cs1302.math.Calculator` and `cs1302.math.Driver`.
- **Static Calculation**: Tracing iterative multiplication via loops in a static helper method.
- **Console Output**: Formatted printing with `printf`.

## Files

- `cs1302/math/Calculator.java`: Multiply helper method.
- `cs1302/math/Driver.java`: Driver class invoking `Calculator.multiply`.
