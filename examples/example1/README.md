# Example 1: Enums & Enum Constants

This example demonstrates how Java enumerated types (`enum`) and their static constants are traced on the heap.

## Concepts Illustrated

- **Java Enums**: `Day` and `MealType` enums.
- **Enum References**: Assigning an enum constant (`MealType.BREAKFAST`) to a local variable.
- **Method Execution**: Calling methods like `hashCode()` on enum constants.

## Files

- `Driver.java`: Defines `Day`, `MealType`, and demonstrates enum variable assignment.
