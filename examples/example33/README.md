# Example 33: Guest Standard Input with java.lang.IO

This example demonstrates providing standard input (`System.in`) to a visualized Java program that reads from standard input using `java.lang.IO.readln`.

## Concepts Illustrated

- **Guest Standard Input**: Supplying standard input via `--stdin` to populate `System.in`.
- **java.lang.IO Preview Support**: Tracing programs using `java.lang.IO.readln` and `java.lang.IO.println` with automatic `--enable-preview` handling.
- **Visualizer Stdin Display**: Input displayed in the visualizer's stdin display element (`#stdinWrap`).

## Files

- `cs1302/io/Driver.java`: Main driver demonstrating `java.lang.IO` reading from standard input.
